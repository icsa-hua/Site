GPT Game

«Γίνε ChatGPT»: μάντεψε την επόμενη λέξη και δες τι «σκέφτεται» ένα πραγματικό γλωσσικό μοντέλο.

1 Σχετικά

Μια διαδραστική επίδειξη πρόβλεψης της επόμενης λέξης, που δείχνει σε διαφορετικές ηλικίες πώς ένα LLM χτίζει μια πρόταση, ένα token τη φορά. Οι επισκέπτες διαλέγουν επίπεδο (Δημοτικό 7–12, Γυμνάσιο 12–15 ή Λύκειο 15–18) και το παιχνίδι προσαρμόζεται: οι μικρότεροι διαλέγουν ανάμεσα σε λίγες επιλογές τη λέξη που θα έλεγε ένα «ρομπότ», ενώ οι μεγαλύτεροι βλέπουν τις πιθανότητες των tokens, το surprisal σε bits και ένα ρυθμιστικό θερμοκρασίας που κάνει τις επιλογές του μοντέλου πιο προβλέψιμες ή πιο χαοτικές. Στόχος είναι μια αφηρημένη ιδέα, το πώς ένα LLM «σκέφτεται» το νόημα, να γίνει ορατή και να παιχτεί σε κάθε ηλικία.

2 Προεπισκόπηση

Τα τρία επίπεδα: από την επιλογή μιας λέξης μέσα από λίγες επιλογές μέχρι τις μπάρες πιθανοτήτων για το επόμενο token με ζωντανό έλεγχο θερμοκρασίας.
